## 1. Objet

Le Lost Signal Narrative Framework contient une histoire et des médias de démonstration destinés à montrer le fonctionnement du Framework et à faciliter son apprentissage.

Ce contenu n’est pas vendu comme un pack d’assets et n’est pas inclus dans l’autorisation permettant de commercialiser des Jeux créés avec le Framework.

## 2. Contenu concerné

Sauf indication contraire écrite, le **Contenu de démonstration** comprend :

- les scénarios, dialogues et textes narratifs présents dans `dialogues/` ;
- les personnages, noms, biographies, statuts et éléments narratifs de `story.json` ;
- l’histoire, l’univers, les scènes, les choix et les embranchements de *Maeve — Lost Signal* ;
- les portraits et avatars présents dans `assets/avatars/` ;
- les images présentes dans `assets/images/` ;
- les musiques présentes dans `assets/music/` ;
- les effets et messages audio présents dans `assets/sounds/` ;
- le nom, le logo et l’identité visuelle propres à *Maeve — Lost Signal* ;
- toute autre ressource explicitement marquée comme exemple, démonstration, placeholder ou contenu non redistribuable.

Les scripts, scènes d’interface génériques, composants de runtime, outils d’édition, tests et documentation technique du Framework ne sont pas régis par ce document. Ils sont régis par `LICENSE.md`.

Les composants appartenant à des tiers restent régis par leurs licences respectives, précisées dans `THIRD_PARTY_NOTICES.md` lorsqu’elles sont connues.
